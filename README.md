# A Backend for ClubHub

This is an api built using [express.js](https://www.npmjs.com/package/express), [better-sqlite3](https://www.npmjs.com/package/better-sqlite3), written in [typescript](https://www.npmjs.com/package/typescript)

ClubHub itself is a club management system, that allows for club management and event management for clubs in a school setting, the source code is avialable [here](https://github.com/PolymorFox/ClubHub)
